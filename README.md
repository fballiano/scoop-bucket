# Scoop bucket of Fabrizio Balliano

Scoop manifests for the Windows apps of Fabrizio Balliano.

```powershell
scoop bucket add fballiano https://github.com/fballiano/scoop-bucket
scoop install fballiano/drivecraft
```

| App | Description |
|---|---|
| [DriveCraft](https://drivecraft.fabrizioballiano.com/) | A light, private, open source replacement for the apps of OneDrive, Dropbox, Box, and more. Built on rclone. |

The release workflow of each app updates its manifest in `bucket/`.
